# ТВОЙ ХОД · Android V1

Готовый Android-проект для облачной сборки APK через GitHub Actions.

## Со смартфона
1. Создайте новый пустой репозиторий GitHub.
2. Загрузите СОДЕРЖИМОЕ этого архива в корень репозитория, сохранив папки.
3. Откройте Actions → Build Android APK → Run workflow.
4. После зелёной сборки откройте run → Artifacts → TVOY_HOD_ANDROID_V1.
5. Скачайте ZIP artifact, распакуйте `app-debug.apk` и установите его.

Package: `ru.tvoyhod.app`
Version: 1.0 (1)
Web UI встроен локально в APK через Android WebView/WebViewAssetLoader.
